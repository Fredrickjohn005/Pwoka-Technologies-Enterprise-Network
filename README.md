# Pwoka-Technologies-Enterprise-Network
CCNA 3 multi-site enterprise network design and implementation using Cisco Packet Tracer.
Pwoka Technologies Ltd. — Multi-Site Enterprise Network Infrastructure

Project Description

This project involves the design and implementation of a multi-site enterprise network infrastructure for Pwoka Technologies Ltd. The network connects a multi-department Head Office to a geographically remote Branch Office using Cisco networking technologies and Cisco Packet Tracer.

The project implements VLAN segmentation, inter-VLAN routing, EIGRP dynamic routing, HSRP gateway redundancy, EtherChannel, STP, DHCP, and network security features including SSH, ACLs, Port Security, and DHCP Snooping. The network was tested in Cisco Packet Tracer to verify connectivity, routing, redundancy, and security.
